# Rimuru: Slime Evolution RPG 💙

Protótipo de fangame RPG **2D com câmera vista de cima** em **Godot 4.4.1**, com desenho vetorial procedural original e exploração livre.

## O que já existe
- Slime azul jogável com animação simples, câmera e movimento em oito direções.
- Floresta ampla com trilhas e santuário.
- 9 espíritos inimigos que perseguem e atacam.
- Ataque direcional, dash e sistema de pontos de vida.
- Essências deixadas pelos inimigos: use a habilidade **Predador** para absorvê-las.
- Evolução a cada 3 essências (mais vida e poder).
- Botões touchscreen para Android e teclas no computador.
- GitHub Actions para verificar a importação e iniciar o projeto sem interface.

## Controles
| Ação | PC | Celular |
| --- | --- | --- |
| Andar | WASD / setas | Botões direcionais |
| Atacar | Espaço / J | ATACAR |
| Absorver | E / K | ABSORVER |
| Dash | Shift | DASH |

## Rodar o projeto
1. Baixe ou clone o repositório.
2. Abra o **Godot 4.4.1** e importe `project.godot`.
3. Aperte **F5** e jogue.

Os sprites finais, árvores de habilidades, animações e exportações Android/Web ainda são próximas etapas. O workflow apenas testa o projeto; **não publica o jogo e não gera APK**.

**Projeto de fã não oficial.** Rimuru e *That Time I Got Reincarnated as a Slime* pertencem aos respectivos titulares. O protótipo não possui afiliação oficial e não inclui artes nem sons extraídos do anime.
